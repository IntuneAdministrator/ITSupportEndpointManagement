## How to use

1. Open the platform category that matches the workload.
2. Open the tool folder and run the PowerShell script.
3. Prefer report/export actions first; pilot any write or delete actions.

## Requirements

- Windows PowerShell 5.1+ or PowerShell 7 where noted
- Appropriate admin rights for the workload you are targeting
- Pilot before production use
