## How to use

1. Open the repair category that matches the symptom.
2. Prefer unified scripts for guided menus; use v0.1 packs when you need the older variants.
3. Run elevated when repairing services, network stack, or Windows Update components.

## Requirements

- Windows PowerShell 5.1+ or PowerShell 7 where noted
- Appropriate admin rights for the workload you are targeting
- Pilot before production use
