# IT Repair & Diagnostic Toolkit

Cross-platform IT repair and diagnostic toolkit with Windows and macOS menus, install/deployment packs, and launcher apps.

## How to use

1. Prefer launchers under `02 - Launchers` (`.exe`, `.command`, or master menu scripts).
2. Use `03 - Install and Deployments` for deployment packs (local, AD, Intune, Jamf).
3. Browse `04 - Windows` / `05 - macOS` for ITSupport and SysAdmin script packs.
4. Read docs under `01 - Documentation` before production use.

## Requirements

- Windows PowerShell 5.1+ or PowerShell 7 where noted
- Appropriate admin rights for the workload you are targeting
- Pilot before production use
