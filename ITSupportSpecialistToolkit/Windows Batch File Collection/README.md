# Windows Batch File Collection

Batch (``.bat``) counterparts for Microsoft 365 repair, Windows repair diagnostics, and Windows Settings helpers.

## Categories

| Folder | Items |
|--------|------:|
| [01 - Microsoft 365 Scripts](./01%20-%20Microsoft%20365%20Scripts) | 1 |
| [02 - Windows Repair](./02%20-%20Windows%20Repair) | 7 |
| [03 - Windows Settings Scripts](./03%20-%20Windows%20Settings%20Scripts) | 10 |

## How to use

1. Open `01` for M365 batch helpers, `02` for repair diagnostics, or `03` for Settings-area scripts.
2. Run `.bat` files from an elevated Command Prompt when the script requires it.
3. Prefer PowerShell siblings in the other toolkit folders when you need richer logic.

## Requirements

- Windows PowerShell 5.1+ or PowerShell 7 where noted
- Appropriate admin rights for the workload you are targeting
- Pilot before production use
