## How to use

1. Open the category for the type of tool you need.
2. Run the vendor executable or script from the tool folder.
3. Prefer offline/portable copies from trusted sources; scan before use on production PCs.

## Requirements

- Windows PowerShell 5.1+ or PowerShell 7 where noted
- Appropriate admin rights for the workload you are targeting
- Pilot before production use
