## How to use

1. Open the Settings-area category you need.
2. Run the PowerShell script as an elevated user when required.
3. Confirm the target OS (Windows 10/11) before making system changes.

## Requirements

- Windows PowerShell 5.1+ or PowerShell 7 where noted
- Appropriate admin rights for the workload you are targeting
- Pilot before production use
