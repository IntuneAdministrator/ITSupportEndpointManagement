# IT Support and Endpoint Management

A curated technical portfolio for Microsoft Intune, Microsoft 365, endpoint engineering, Windows administration, IT support, automation, and front-end development.

The repository brings together production-oriented scripts, deployment resources, diagnostics, policy examples, and documentation developed or organized for practical IT operations.

## Getting started

1. Select the collection that matches your task.
2. Read that collection's `README.md` and any documentation in the target subfolder.
3. Review scripts before execution.
4. Test changes in a lab, virtual machine, or limited pilot group.
5. Use least-privilege accounts and approved change controls in production.

---

## Requirements

Requirements vary by collection:

- Windows 10 or Windows 11 for most endpoint and support tools
- macOS where a script or profile is explicitly designed for macOS
- Windows PowerShell 5.1 or PowerShell 7, depending on the tool
- Appropriate Microsoft Intune, Microsoft 365, Entra ID, or local administrator permissions
- A modern web browser for the website portfolio

---

## Security and operational notice

Some scripts can change device configuration, security settings, applications, user accounts, or cloud resources. They are provided for controlled administrative use.

- Review all code before execution.
- Test in a non-production environment first.
- Back up affected systems and data.
- Use only software and activation methods for which your organization has valid licensing.
- Do not store credentials, tokens, certificates, tenant data, or customer information in the repository.
