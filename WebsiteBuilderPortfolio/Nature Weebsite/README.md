# Nature Weebsite

Nature-focused marketing site with multi-page layout and dark mode toggle.

## Entry

Open `index.html`.

## Pages

| Page |
|------|
| `index.html` |
| `about.html` |
| `services.html` |
| `pricing.html` |
| `contact.html` |

## How to use

1. Open `index.html` in a browser, or serve the folder with a local HTTP server.
2. Customize `styles.css`, `script.js`, and image folders (`Home/`, `About/`, `Services/`, `Contact/`).
