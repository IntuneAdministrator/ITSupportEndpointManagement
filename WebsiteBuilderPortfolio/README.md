# Website Builder Portfolio

A front-end portfolio containing **10 responsive static websites** built with semantic HTML, modern CSS, and vanilla JavaScript. Each project is self-contained and demonstrates a different industry, layout, content structure, and visual approach.

The projects require no framework, build process, or backend. They can be reviewed directly in a browser or served through a lightweight local web server.

**Author:** [Allester Padovani](https://www.linkedin.com/in/allester-padovani/)  
**GitHub:** [IntuneAdministrator](https://github.com/IntuneAdministrator)

---

## Portfolio highlights

- Responsive layouts for desktop, tablet, and mobile
- Semantic HTML and accessible navigation patterns
- CSS Grid, Flexbox, custom properties, and reusable styling
- Vanilla JavaScript interactions without framework dependencies
- Industry-specific layouts, calls to action, and content hierarchy
- Self-contained projects suitable for local review

## Tech stack

- HTML5 (semantic markup, skip links, ARIA labels)
- CSS3 (Flexbox, Grid, custom properties, responsive layouts)
- Vanilla JavaScript (navigation, carousels, carts, theme toggles)
- Google Fonts and Font Awesome (where used)
- SVG logos and favicons

## Preview locally

**Option 1 — open a file**

Double-click `index.html` inside any project folder, or drag it into your browser.

**Option 2 — local server (recommended)**

```bash
# Python 3
python -m http.server 8080

# Node.js (npx)
npx serve
```

Then visit `http://localhost:8080` and browse into a project folder.

## Notes

These are **front-end prototypes**. Contact forms, checkout, and donations are UI-only and do not process real data. Some images may load from CDNs, so an internet connection can be required for the full visual experience.

Names, branding, organizations, products, and testimonials used in the demos are fictional or included solely for portfolio presentation unless explicitly stated otherwise.
