# Modern Store

Static e-commerce demo with product grid, checkout UI, and automatic dark mode (`prefers-color-scheme`).

## Entry

Open `index.html`.

## Pages

| Page |
|------|
| `index.html` |
| `about.html` |
| `products.html` |
| `pricing.html` |
| `checkout.html` |
| `contact.html` |

## How to use

1. Open `index.html` in a browser, or serve the folder with a local HTTP server.
2. Customize products and styles under `assets/`.
