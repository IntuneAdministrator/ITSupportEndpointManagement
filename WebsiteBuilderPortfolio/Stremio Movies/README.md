# Stremio Movies

Streamio — movie and series streaming UI demo with catalog, about, pricing, and contact pages.

## Entry

Open `index.html`.

## Pages

| Page |
|------|
| `index.html` |
| `pages/catalog.html` |
| `pages/about.html` |
| `pages/pricing.html` |
| `pages/contact.html` |

## How to use

1. Open `index.html` in a browser, or serve the folder with a local HTTP server.
2. Customize `css/`, `js/`, and `pages/`.
