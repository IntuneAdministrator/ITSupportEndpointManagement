# Warranty Remediation

Proactive remediation related to Dell Command | Monitor (DCM) out-of-warranty status. Remediation script is marked **Do Not Use**.

## Packages

| Package | Notes |
|---------|-------|
| `DCM Out of Warranty` | Detection available; remediation marked **do_not_use** — do not assign remediation in production |

## How to use

1. Open the package folder and review the detection script.
2. Prefer detection-only or reporting use unless you intentionally replace the remediation.
3. Do not deploy `Intune_9_remediation_DCM_OutofWarranty_do_not_use.ps1` as written.
