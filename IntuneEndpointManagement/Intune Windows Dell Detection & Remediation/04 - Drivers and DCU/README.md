Proactive remediation for critical drivers via Dell Command | Update (DCU).

## How to use

1. Open the package folder and review detection / remediation scripts.
2. Ensure Dell Command | Update is installed and allowed to run on target devices.
3. Deploy as an Intune Remediation; pilot reboot / maintenance windows carefully.
