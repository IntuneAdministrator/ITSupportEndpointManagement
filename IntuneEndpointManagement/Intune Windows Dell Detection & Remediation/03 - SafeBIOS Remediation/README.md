# SafeBIOS Remediation

Proactive remediation for Dell SafeBIOS Indicators of Attack (IoA) status.

## Packages

| Package |
|---------|

## How to use

1. Open the package folder and review detection / remediation scripts.
2. Deploy as an Intune Remediation on Dell devices with SafeBIOS available.
3. Pilot before broad assignment; confirm IoA reporting matches your security process.
