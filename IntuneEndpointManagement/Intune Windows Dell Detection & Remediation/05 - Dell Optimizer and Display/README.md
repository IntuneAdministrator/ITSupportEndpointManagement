# Dell Optimizer and Display

Proactive remediations for Dell Optimizer (Teams app performance) and Dell Display Manager ComfortView.

## Packages

| Package |
|---------|
| `Dell Optimizer Teams Performance` |
| `DDM ComfortView` |

## How to use

1. Open the package folder and review detection / remediation scripts.
2. Confirm Dell Optimizer and/or Dell Display Manager are present where required.
3. Deploy as Intune Remediations; prefer system context unless the script targets the user session.
