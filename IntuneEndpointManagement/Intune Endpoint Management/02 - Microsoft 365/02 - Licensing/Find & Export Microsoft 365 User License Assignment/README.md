# Find & Export Microsoft 365 User License Assignment

Finds and exports how Microsoft 365 licenses are assigned to users.

## Entry

`FindM365LicenseAssignmentPath.ps1`

## How to use

1. Review the script or app files in this folder.
2. Run with an account that has the required Entra ID / Intune / Microsoft 365 permissions.
3. Prefer read-only / report mode first when available; pilot any write or delete actions.
