# Company Portal

Company Portal system tray helper for Intune Win32 deployment.

## Tools

| Tool |
|------|
| `Company Portal System Tray Tool` |

## How to use

1. Open the tool folder (`sources`, `install.intunewin`).
2. Package/deploy as an Intune Win32 app.
3. Pilot on a test device group.
