# Device Troubleshooter

GUI tool to troubleshoot Intune-managed Windows devices.

## Tools

| Tool |
|------|
| `Intune Device Troubleshooter` |

## How to use

1. Open the tool folder.
2. Run `Start-DeviceTroubleshooter.ps1`.
3. Use with an account that can query Intune device data.
