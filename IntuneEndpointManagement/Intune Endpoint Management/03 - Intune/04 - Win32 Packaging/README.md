# Win32 Packaging

Downloader / helper for Intune Win32 (`.intunewin`) packaging workflows.

## Tools

| Tool |
|------|
| `Intunewin Downloader` |

## How to use

1. Open the tool folder.
2. Launch `IntuneWinDownloader.WpfUi.exe`.
3. Use downloaded packages with Intune Win32 app deployment.
