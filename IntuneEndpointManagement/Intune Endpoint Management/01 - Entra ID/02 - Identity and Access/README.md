# Identity and Access

Entra ID identity reports: admin roles, MFA status, password change/expiry, and guest users.

## Tools

| Tool |
|------|
| `Export Office 365 Admin Role` |
| `Export Office 365 Users MFA Status` |
| `Export Office 365 Users' Last Password Change Date` |
| `Identify Guest Users and Their Group Membership Details` |

## How to use

1. Open the tool folder under this workload.
2. Review the entry script.
3. Run with least-privilege Entra read roles; export before acting on accounts.
