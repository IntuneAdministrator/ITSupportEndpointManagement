# Conditional Access

Export and analyze Microsoft Entra Conditional Access policies.

## Tools

| Tool |
|------|

## How to use

1. Open the tool folder under this workload.
2. Review the entry script.
3. Run with an Entra role that can read Conditional Access policies.
