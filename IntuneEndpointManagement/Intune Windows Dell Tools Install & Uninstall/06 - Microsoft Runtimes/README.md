# Microsoft Runtimes

Install / uninstall / detection scripts for Microsoft .NET-related runtimes often required by Dell tools.

## Packages

| Package |
|---------|
| `Microsoft .NET Runtime 8` |
| `Microsoft ASP.NET 8` |

## How to use

1. Open the package folder and pair scripts with the official Microsoft runtime installer.
2. Deploy as Intune Win32 prerequisites before dependent Dell apps (for example SupportAssist / Trusted Device).
3. Confirm architecture (x64) and version detection before broad rings.
