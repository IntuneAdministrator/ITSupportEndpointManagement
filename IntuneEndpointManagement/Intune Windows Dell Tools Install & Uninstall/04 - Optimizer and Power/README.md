# Optimizer and Power

Per-app install / uninstall / detection scripts for Dell Optimizer and Dell Power Manager.

## Packages

| Package |
|---------|
| `Dell Optimizer` |
| `Dell Power Manager` |

## How to use

1. Open the package folder and pair scripts with the vendor installer.
2. Deploy as Intune Win32 apps; confirm hardware / SKU support before broad rings.
3. Pilot reboot and dependency requirements carefully.
