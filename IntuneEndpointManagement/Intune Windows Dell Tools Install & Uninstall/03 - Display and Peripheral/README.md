# Display and Peripheral

Per-app install / uninstall / detection scripts for Dell display and peripheral management tools.

## Packages

| Package |
|---------|
| `Dell Display Manager` |
| `Dell Display Manager 2` |
| `Dell Display and Peripheral Manager` |
| `Dell Peripheral Manager` |

## How to use

1. Open the package folder that matches the product you deploy (DDM vs DDM 2 vs combined manager).
2. Pair scripts with the vendor installer in an Intune Win32 app.
3. Pilot on devices that have the matching Dell display / peripheral hardware.
