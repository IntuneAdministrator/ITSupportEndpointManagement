# x64

64-bit `ServiceUI.exe` for interactive UI during system-context Win32 installs on 64-bit Windows.

## Files

| File | Purpose |
|------|---------|
| `ServiceUI.exe` | Launch interactive process in the user session (x64) |

## How to use

1. Copy into your Win32 app source folder.
2. Reference it from the install command (with your interactive payload).
3. Prefer this build on 64-bit Windows 10/11 devices.
