# Disable Sharing and Services

Disable sharing services and legacy protocols (Bluetooth/file/printer sharing, SMB1, remote services, etc.).

## Packages

| Package |
|---------|
| `Disable Bluetooth Sharing` |
| `Disable Bonjour Advertising Services` |
| `Disable CD or DVD Sharing` |
| `Disable creation of '.DS_Store' -files` |
| `Disable File Sharing` |
| `Disable Guest Access to Shared Folders` |
| `Disable HTTP Server` |
| `Disable Internet Sharing` |
| `Disable NFS Server` |
| `Disable Printer Sharing` |
| `Disable Remote Apple Events` |
| `Disable Remote Login` |
| `Disable Remote Management` |
| `Disable Screen Sharing` |
| `Disable SMB 1, NetBIOS and netbiosd` |

## How to use

1. Open the package folder you need.
2. Follow any package-level `readme.md` for install parameters, profiles, or prerequisites.
3. Pilot on a test Mac before assigning broadly in Intune.
