# Toast Notifications

User-facing toast remediations for AV, battery, firewall, CPU/memory, disk, network, updates, printers, and reboot required.

## How to use

1. Open the package folder and review detection / remediation scripts.
2. Deploy as an Intune Remediation (detection + remediation).
3. Pilot before broad rings.
